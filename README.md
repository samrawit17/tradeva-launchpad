# Tradeva Launchpad

Modern, peer-to-peer (P2P) cryptocurrency platform landing page & launchpad launching in 2026.

## Features

- **P2P Escrow & Trading:** Secure smart contracts and automated dispute resolution.
- **Hot & Cold Wallets:** Multi-signature custody with real-time balance tracking.
- **Smooth Navigation:** Kinetic momentum scrolling powered by Lenis.
- **Custom Typography:** Limitype Copixel display font integration.
- **Floating Header & Dynamic Footer:** Rich interactive components with responsive navigation.

## Tech Stack

- **Framework:** TanStack Start (React 19)
- **Styling:** Tailwind CSS v4 & Lucide Icons
- **Motion:** Lenis smooth scrolling
- **Build & Server:** Vite & Nitro
- **Deployment:** Vercel

## Local Development

Install dependencies and start the dev server:

```bash
bun install
bun run dev
```

Build for production:

```bash
bun run build
```
